## 验收切片

1. 混合 layer 同页/跨页合并保留原始 ID、layer、page、bbox、readingOrder，拆分可恢复；普通点击替换、Ctrl 增减，来源空白和 Esc 只清除当前选择/锁定。
2. 页边缘纯数字、罗马数字和“第 X 页/共 Y 页”默认排除且可恢复；稳定重复页眉页脚仅建议排除，标题、型号、章节、版本和法律限制不自动排除。
3. 空识别区域允许选择类型、填写人工文字并保存；生成的 Chunk 保留 page、bbox 和 human transcription provenance，不写回 Parsed Document。
4. Configuration Draft 在未生成、dirty、生成中、失败时展开；干净成功 Preview 和 Draft 默认收起，用户展开/固定展开优先。
5. 人工 Preview 由服务端计算与自动 Preview 等价的 Embedding/Context eligibility 和 candidate reasons；Preview 显示“采用 Draft 后可生成”，Draft 保持 Context 工具可用。
6. 区分内容不合格与 Context 服务未配置；无模型时 Draft 仍允许人工 Context 保存，只禁用模型生成。
7. 主界面与 evidence 不显示内部原因码、服务器路径或原始异常；诊断信息仅进入受控诊断包。
